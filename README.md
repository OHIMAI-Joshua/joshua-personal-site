# Joshua Ohimai — Personal Link Hub

This repository contains a single-page personal link hub, based on the visual approach of the original Webstudio Link-in-Bio template.

## Current version

- `index.html` is the working homepage and includes its page styling.
- `styles.css` and `favicon.svg` are earlier prototype assets; they are not required by the current homepage.
- The site uses a remote background image from the Webstudio demo site. Replace this with a checked-in local image before permanent launch.
- The profile-photo area still uses a **JO** placeholder. The supplied original portrait has not yet been committed to GitHub.
- Current and previous organizations have brief descriptions and links where available, with no years.

## Preview on GitHub Pages

Go to **Settings → Pages** for this repository. Under **Build and deployment**, select **Deploy from a branch**, use **main** and **/(root)**, and click **Save**. GitHub Pages can then serve this repository's `index.html` without requiring Replit, a build step, or hosting purchases. Wait for GitHub to show the actual published URL; it may take a few minutes.

## Future edits

Edit `index.html` directly or make changes through a code editor connected to GitHub. This site is intended to remain simple and portable.

## Project status

The design and content are in GitHub. **Photo upload, a fully local asset pack, and visual acceptance against the original Webstudio export remain outstanding**. Do not consider this the final production launch.
