# Joshua Ohimai — personal website

A minimal, responsive, static personal link hub. No build dependencies, no backend, and no paid hosting required to edit the code.

## Files
- `index.html` — content, links, company cards.
- `styles.css` — design and mobile layout.
- `favicon.svg` — JO monogram.

## Run or deploy
Open `index.html` locally, import the repository in Replit, or connect this GitHub repository to Cloudflare Pages. No build command needed; publish directory is the repository root.
